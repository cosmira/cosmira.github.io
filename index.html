soda.php Your team's limits
<?php

use Cosmira\Soda\Config\Soda;
use Cosmira\Soda\Rules\Structure\MaxDependencies;
use Cosmira\Soda\Rules\Complexity\MaxCyclomaticComplexity;

return Soda::configure()
    ->withPaths(['src/'])
    ->with([
        new MaxDependencies(6),
        new MaxCyclomaticComplexity(8),
    ]);

Save this file in your project root, then run vendor/bin/soda. These two checks flag classes with more than six constructor dependencies and methods with cyclomatic complexity above eight.

To customize the full standard set, start with vendor/bin/soda init and edit its generated rule objects.

Soda / Design & maintainability

One business rule. One place to change it.

Find business decisions reimplemented by callers and object setup copied from place to place. Soda points to the repetition so you can review where that behavior belongs.

For exampleA page, a notification and a search index each check whether a post is published and not deleted. Soda flags the repeated decision and suggests giving Post a single isPubliclyVisible() method.
