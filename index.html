Laravel Pint / Code style

A consistent way to write PHP.

Keep formatting consistent with your chosen code style. Pint handles details such as spacing, indentation and braces, so the team can focus on the change.

For exampleBring differently formatted files into the same coding style.

Explore Laravel Pint
Rector / Refactoring

Keep your PHP moving forward.

Automate supported refactorings and PHP upgrades with the rules you enable. Rector proposes code changes that your team can review and apply.

For exampleReplace a legacy pattern with its supported modern equivalent.

Explore Rector
PHPStan / Static analysis

Find bugs before runtime.

Inspect types, method calls and other potential errors without running your application. PHPStan helps the team catch mistakes earlier in development.

For exampleSpot a call that passes a string where an integer is required.

Explore PHPStan
Soda / Structure & clarity

Your team’s taste, made repeatable.

Put expectations about structure, complexity and naming into checks your team can run locally and in CI.

For exampleA method can be well formatted and type-correct, yet still exceed your team’s length limit.

Find the checks that fit
PHPUnit / Tests & behavior

Check that the behavior holds.

Run the tests your team writes to check expected results and catch regressions. PHPUnit executes your code and compares the outcomes with your assertions.

For exampleVerify that applying a discount produces the expected total, including edge cases.

Explore PHPUnit
